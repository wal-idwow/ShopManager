# MiniShop Requirements

## Core Stack
- Node.js 18+ (Node.js 20 recommended)
- npm 9+
- Express.js backend
- React 18 frontend
- SQLite via better-sqlite3

## Backend Dependencies
- express
- cors
- better-sqlite3

## Frontend Dependencies
- react
- react-dom
- react-router-dom
- react-query
- axios
- react-scripts

## Test Dependencies
- jest
- supertest (backend API tests)
- @testing-library/react
- @testing-library/jest-dom

## Optional for Next Phase (Authentication)
- jsonwebtoken
- bcryptjs
- dotenv

## Environment Variables
- PORT (default backend port: 3000)
- REACT_APP_API_URL (optional; leave empty for same-origin in deployed mode)

## Install Commands

### Install Root Tooling
```bash
cd /home/medal/Shop_Manager
npm install
```

### Install Backend
```bash
cd /home/medal/Shop_Manager/backend
npm install
```

### Install Frontend
```bash
cd /home/medal/Shop_Manager/frontend
npm install
```

## Build and Run

### Production-style Run (recommended)
```bash
cd /home/medal/Shop_Manager/frontend
npm run build
cd /home/medal/Shop_Manager
node backend/index.js
```

### Public Tunnel (for device testing)
```bash
cd /home/medal/Shop_Manager
npx ngrok http 3000
```
