# Requirements for Daily Financial Clarity Tool

## Backend Requirements
- **Node.js**: JavaScript runtime for backend development.
- **Express.js**: Lightweight framework for building APIs.
- **SQLite**: Local database for storing transactions.
- **Firebase** (optional): For cloud-based storage and sync.
- **dotenv**: For managing environment variables.
- **bcrypt**: For password hashing (if authentication is implemented).
- **Jest**: For backend testing.

### Backend Installation Commands
```bash
npm install express sqlite3 dotenv bcrypt jest
```

## Frontend Requirements
- **React Native**: Framework for building cross-platform mobile apps.
- **React Navigation**: For navigation between screens.
- **Expo** (optional): For easier development and testing.
- **Axios**: For making API requests.
- **Styled Components**: For styling the app.

### Frontend Installation Commands
```bash
npm install react-native react-navigation axios styled-components
```

## Testing Requirements
- **Jest**: For unit testing.
- **React Native Testing Library**: For testing React Native components.

### Testing Installation Commands
```bash
npm install --save-dev jest @testing-library/react-native
```

## Additional Notes
- Use `npm init` to initialize the project.
- Ensure Node.js and npm are installed.
- For React Native, follow the official setup guide: https://reactnative.dev/docs/environment-setup.
